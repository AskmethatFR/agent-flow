Closed answer for S2
     A vitest run that fails (exit 1) is delivered as PostToolUseFailure, never as PostToolUse; a passing run
     as PostToolUse. S2 must register BOTH, matcher "Bash", on the same writer command.
     Keys the writer reads, by event:
       field                 PostToolUse (pass)                  PostToolUseFailure (fail)
       agent_type            agent_type                          agent_type
       cwd                   cwd                                 cwd
       command               tool_input.command                  tool_input.command
       duration              duration_ms                         duration_ms
       interrupted           tool_response.interrupted           is_interrupt  (no tool_response)
       exit code             implied 0                           "Exit code N" prefix of error
       tool_use_id           tool_use_id                         tool_use_id
     A PostToolUse with tool_response.backgroundTaskId (and timedOutAfterMs) is a run that has not ended:
     the writer must not treat it as a finished run, whatever its interrupted value.
     No PostToolUse key says a run failed, so the pass/fail of a run is the event name, not a payload field.
